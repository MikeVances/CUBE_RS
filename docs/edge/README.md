# 📚 EDGE Documentation

Документация для системы мониторинга промышленных контроллеров КУБ

## 📋 Список документов:

### 🚀 **USER_DEPLOYMENT_GUIDE.md**
**Основное руководство для пользователей**
- Пошаговая настройка от получения устройства до работы
- Конфигурация 10 КУБ устройств (КУБ-1063 + КУБ-1112)
- Настройка Telegram бота для мониторинга
- Решение типовых проблем и обслуживание

### 🔧 **ADDING_NEW_DEVICE.md**
**Руководство по добавлению новых устройств**
- Пошаговое добавление КУБ-1150 (пример)
- Работа с Variable System и адаптерами
- Checklist для разработчиков (30 мин - 2 часа)

### 🏗️ **MULTI_DEVICE_ARCHITECTURE.md** 
**Техническая документация архитектуры**
- Описание гибкой многоустройственной архитектуры
- Variable System и Device Registry
- Для разработчиков и системных интеграторов

### 📊 **КУБ-1063_modbus_registers.pdf**
**Техническая спецификация КУБ-1063**
- Карта Modbus регистров для системы вентиляции
- Описание переменных и специальных значений
- Справочная информация для разработки

### 🔥 **КУБ-1112_modbus_registers.pdf**
**Техническая спецификация КУБ-1112**
- Карта Modbus регистров для системы горелок/обогрева
- Управляющие команды и мониторинг
- Справочная информация для разработки
