# 830 Series VFD — Группа F0 (базовые параметры)

Этот файл составлен по странице руководства (“Parameters”, раздел 3.1.1 F0 Parameter Group — Basic Parameters of Synchronous Motor) из предоставленного фото. Значения «по умолчанию» зависят от модели привода; корректные установки сверяйте с паспортом двигателя (шильдик).

## Обозначения в таблицах параметров

- Параметр можно изменять как при остановленном, так и при работающем приводе.
- Параметр нельзя изменять, если привод находится в состоянии «RUN» (только при останове).
- Параметр является измеряемым в реальном времени и недоступен для изменения (только чтение).
- Заводской (factory) параметр — доступен только производителю, не доступен пользователю.

### F0‑06: Motor Parameter Autotune

- 0: No operation — автонастройка не выполняется.
- 1: Static parameter identification — статическая идентификация параметров. Использовать, если двигатель нельзя полностью отсоединить от нагрузки и он не может свободно вращаться.
- 2: Dynamic parameter identification — динамическая идентификация. Использовать, если двигатель полностью отсоединён от нагрузки и может свободно вращаться.

Примечание: после восстановления заводских установок, смены модели или изменения уровней мощности/напряжения двигателя рекомендуется повторно выполнить идентификацию параметров, чтобы режим векторного управления работал оптимально.

## Дополнительные примечания

- Параметры F0‑07…F0‑09 относятся к параметрам двигателя (индуктивности и сопротивление). Для большинства типовых пусконаладок менять их вручную не требуется, если выполнена корректная идентификация (F0‑06) и значения взяты из документации на двигатель.
- Все численные пределы и доступность изменения параметров зависят от конкретной модели привода.

### Примечание к F0‑14 (Switching Frequency)

- Пониженная частота переключения уменьшает потери на переключение инвертора, но увеличивает гармоники тока и нагрев двигателя.
- Повышенная частота переключения снижает пульсации тока и акустический шум, но увеличивает потери и нагрев инвертора. Выбирайте компромисс исходя из модели и условий работы.

### F0‑19: Command Source Selection

- 0: Panel control — управление с панели (RUN/STOP).
- 1: Terminal control — дискретные входы; по умолчанию DI1 — вперёд, DI2 — реверс.
- 2: Communication control — управление по Modbus RTU (RS‑485/RS‑232 — зависит от модели).
- 3: Auto start after power on — автозапуск после подачи питания.

### F0‑20: Main Frequency Source Selection

- 0: Function code setting, power‑off memory — частота задаётся параметрами; сохраняется при выключении.
- 1: Panel potentiometer — потенциометр на панели.
- 2: AI1 — аналоговый вход 1.
- 3: AI2 — аналоговый вход 2 (в ряде моделей «reserved»).
- 4: Multi‑segment command — многоступенчатое задание частоты по дискретным входам.
- 5: PLC — встроенная логика/ПЛК.
- 6: Constant pressure water supply — режим поддержания давления.
- 7: General PID — общий ПИД‑контур.
- 8: Communication settings — задание частоты по связи (Modbus).
- 9: Reserved — зарезервировано.

## Настройки RS‑485 и Modbus RTU (важные тонкости)

- Физическое подключение
  - Интерфейс: RS‑485 (2‑проводный). Клеммы на VFD обычно подписаны как A/B или D+/D−; рядом может быть COM/SGND (общая земля).
  - Провода: A↔A (D+), B↔B (D−), общий GND ↔ COM/SGND. Скрутка (витая пара) для A/B желательна.
  - Терминация: 120 Ω между A и B на конце линии (на стороне VFD или адаптера). В минимальной «ПК ↔ VFD» — достаточно одного терминатора, если на адаптере нет встроенного.
  - Fail‑safe (bias): подтяжка A к Vcc и B к GND — часто встроена в USB‑RS485 адаптеры.

- Параметры на VFD (по разделам F2/F0)
  - F2‑17 Inverter Address — slave ID узла Modbus (например, 1; значение 0 — широковещание, отвечать нельзя).
  - F2‑18 Baud Rate — скорость, например 9600 бод.
  - F2‑19 Data Format — формат кадра, обычно 8‑N‑1.
  - F2‑20 Communication Timeout — внутренняя диагностика связи (порт не выключает).
  - Для управления по Modbus: F0‑19=2 (Communication control), источник задания частоты можно поставить F0‑20=8 (Communication settings). Для простого чтения это не обязательно.

- Клиент и библиотека (pymodbus)
  - В pymodbus 3.x при создании последовательного клиента используйте RTU‑фреймер: `framer=FramerType.RTU`.
  - Методы чтения в 3.x ожидают аргумент `slave` (а не `unit`). Если передать `unit`, адрес останется 0 (broadcast), и ведомый не ответит. В 2.x использовался `unit`.
  - Рекомендуемые настройки порта: скорость из F2‑18; `bytesize=8`, `parity=N`, `stopbits=1`, `timeout≈0.3–0.5 s`.
  - На macOS предпочтителен порт `cu.*` (например, `/dev/cu.usbserial-2130`), а не `tty.*`.

- Адреса и функции чтения
  - Карта U0‑xx из инструкции соответствует адресу базы 0x1000 (например, U0‑00 → 0x1000).
  - Большинство параметров мониторинга доступны по FC03 (Holding Registers). На некоторых моделях могут дублироваться по FC04 (Input Registers).

- Быстрый запуск live‑теста из репозитория
  - Обязательные переменные окружения (пример):
    - `VFD_ENABLE_LIVE_TEST=true`
    - `VFD_SERIAL_PORT=/dev/cu.usbserial-2130`
    - `VFD_SLAVE_ID=1`
    - `VFD_BAUDRATE=9600`
  - Необязательные (оставьте по умолчанию, если не уверены):
    - `VFD_PARITY=N` `VFD_STOPBITS=1` `VFD_BYTESIZE=8` `VFD_TIMEOUT=0.5` `VFD_RETRIES=0` `VFD_INTER_DELAY=0.08`
    - `VFD_READ_FN=holding` `VFD_ADDR_OFFSET=0`
    - Для диагностики: `VFD_CALIBRATE=true`, `VFD_SCAN_IDS=1-16` (перебор ID), `VFD_READ_FN=auto`, `VFD_ADDR_OFFSET=auto`.

- Типовые симптомы и причины
  - «No response (0 bytes)»: перепутаны A/B, нет терминатора/общего GND, неверный ID, неверный ключ адреса (`slave` vs `unit`), RS‑232 вместо RS‑485.
  - «IllegalAddress»: часть регистров не реализована — нормально для истории ошибок и прочих необязательных групп.
- «Invalid CRC/мусор»: не совпадает скорость/паритет или плохое согласование линии.

## Коды ошибок и решения (перевод из руководства)

Ниже приведены типовые неисправности, отображаемые на панели, их возможные причины и рекомендации по устранению. Список носит справочный характер; при сложной диагностике обращайтесь в техподдержку.

| Код | Название (панель) | Возможные причины | Рекомендации |
|-----|--------------------|-------------------|--------------|
| Err01 | Защита силового модуля (Inverter Unit Protection) | 1) Короткое замыкание/пробой на выходе; 2) Слишком длинный кабель двигателя; 3) Перегрев модуля; 4) Ослабли внутренние соединения; 5) Неисправна плата управления; 6) Неисправна драйверная плата; 7) Неисправен силовой модуль | Устранить внешние неисправности; установить реактор/выходной фильтр; проверить фильтр и вентилятор; проверить и восстановить соединения; при необходимости — техподдержка/ремонт |

Часто встречающиеся неисправности (без кода на дисплее):

- Нет индикации при включении: нет питания/занижено напряжение; неисправна плата выпрямителя/буферный резистор/плата; обрыв шлейфа панели — проверить питание, напряжение DC‑шины, соединения; при необходимости — сервис.
- Частые срабатывания Err14 (перегрев): завышена частота переключения/забит фильтр/неисправен вентилятор — снизить частоту ШИМ (F0‑14), очистить фильтр, заменить вентилятор.
- Двигатель не вращается после пуска: проверить кабели и сам двигатель; параметры мотора; контакт шлейфа между платами; возможна неисправность драйверной платы.
- DI‑входы «не работают»: проверьте параметры группы F2, внешний сигнал, кабели.
- Частые перегрузки/перенапряжения: неправильно заданы параметры двигателя, слишком короткие времена разгона/торможения, колебания нагрузки — пересмотреть уставки и выполнить автонастройку.
