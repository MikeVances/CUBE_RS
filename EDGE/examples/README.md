# Examples directory

Здесь собраны шаблонные конфигурации и скрипты. Папка `config/` внутри повторяет структуру рабочей `config/` директории (конфиги, логи, secrets) и служит ориентиром при развертывании. 

Эти файлы не используются рантаймом напрямую — скопируйте нужные шаблоны в корневой `config/` и адаптируйте под своё окружение.
